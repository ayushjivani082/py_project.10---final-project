Student Project Collection

1. Projects Included

1. COVID-19 Data Analysis
2. Global Happiness Report Analysis
3. Titanic Survival Analysis
4. Air Quality Analysis

2. Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance

3. Project Descriptions

Project 1: COVID-19 Data Analysis

- Analyze confirmed COVID-19 cases.
- Study deaths and recoveries.
- Compare countries.
- Create data visualizations.

Project 2: Global Happiness Report

- Analyze happiness scores.
- Compare different countries.
- Study economic and social factors.
- Create comparison charts.

Project 3: Titanic Survival Analysis

- Analyze passenger survival.
- Compare male and female survival rates.
- Study passenger classes.
- Analyze age and survival.

Project 4: Air Quality Analysis

- Analyze ozone levels.
- Study wind and temperature.
- Create pollution-related visualizations.
- Find statistical information.

Project 5: Stock Market Analysis

- Analyze Apple stock prices.
- Calculate moving averages.
- Study trading volume.
- Visualize historical stock trends.

4. Installation

Install the required libraries:

pip install pandas numpy matplotlib seaborn yfinance jupyter

5. How to Run Projects

1. Open VS Code.
2. Open the project folder.
3. Open the Jupyter Notebook file.
4. Select the Python kernel.
5. Run each cell separately.
6. Check the output and graphs.
7. Save the notebook using Ctrl + S.

6. Automatic CSV Files

Each project generates a separate CSV file after running its final export cell.

- COVID_19_Analysis.csv
- Global_Happiness_Analysis.csv
- Titanic_Survival_Analysis.csv
- Air_Quality_Analysis.csv
- Stock_Market_Analysis.csv

7. Learning Outcomes

After completing these projects, students will learn:

- Loading datasets using Pandas.
- Data cleaning and manipulation.
- Handling missing values.
- Exploratory Data Analysis (EDA).
- Data visualization.
- Statistical analysis.
- Creating graphs.
- Exporting data into CSV files.

8. Conclusion

These five projects provide practical knowledge of Python Data Analysis.

Load Data → Clean Data → Analyze Data → Visualize Data → Save CSV
